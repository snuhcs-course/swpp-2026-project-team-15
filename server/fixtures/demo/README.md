# Deterministic mock input

`mock-photo.png` is a generated64×64 checkerboard, not a food photograph. Its hash selects the unchanged recorded garlic/egg vision fixture. The setup script copies it to the connected phone's Pictures directory, so a fresh clone can exercise gallery→candidate review→inventory→recommendation/detail without keys or manually configuring .env. Mock outcomes do not establish image-recognition accuracy or recipe safety.

The private560-item ZIP is still required and never committed. Unit/connected tests cover error/partial/revised/refused paths separately. Remove the phone copy after a demo if no longer needed. Actual live checks use separate authorized real photos.
