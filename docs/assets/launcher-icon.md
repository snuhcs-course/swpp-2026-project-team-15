# Launcher artwork

The user supplied the green refrigerator wearing a tilted chef hat and requested removal of the two accent strokes on its right. Built-in imagegen performed that edit on November 3, 2026, preserving the cream/green appearance and providing a square background with adaptive-mask safe space.

`android/app/src/main/res/drawable-nodpi/ic_launcher_artwork.webp` is the 512px packaged artwork. Density-specific WebP files are resize/encoding exports of the same selected result. The themed icon is a simplified code-native fridge/chef silhouette. No stock-image download or third-party icon bundle was used for this launcher change. This note records provenance and does not assign a license to the user-provided reference.

Both normal and round adaptive aliases refer to this artwork. Debug, cloudTest and release use the common main resources; only the build's app label/package and endpoint may differ. The reference PNG and imagegen prompt/output record are retained locally in the ignored workspace, rather than referenced as runtime files outside the repository.
