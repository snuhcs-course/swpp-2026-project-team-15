## 발견한 문제와 처리

1. **휴대폰 네트워크:** 처음 목록 확인 시 휴대폰 자체 HTTP 연결에서`Network is unreachable`이 반환됐다. 같은 시각 PC의 서버 health/ready/일반 목록은200이었다. 사용자가 네트워크 연결을 확인한 뒤 휴대폰의 실제 API/목록 검사가 통과했다. 서버 코드나 배포를 수정해 해결한 것으로 기록하지 않는다.
2. **추가 위치 검사의 컴파일 오류:** DpRect에 없는`center`속성을 사용했다가 빌드가 실패했다. 경계 좌표의 평균으로 바꿔 컴파일·휴대폰 검사를 통과했다. AI가 만든 테스트 코드의 실수와 수정이며, 사용자 수동 코드 수정 사례가 아니다.
3. **실제 키보드 검증:** 기존 화면 높이 축소 검증과 별개로`WindowInsets.isImeVisible`이 실제 참인 상황에서 별명 입력/다음 버튼 동작을 확인하는 테스트를 추가했다. 기존 코드가 처음부터 통과한 보완 검사이며 RED→GREEN 제품 버그 수정으로 과장하지 않는다. 에뮬레이터 키보드 표시 설정은 원래0으로 복원했다.
