# 레시피 카드 클릭·AI 재요청 — 2026-11-03

사용자 요청에 따라 현재 이미지 연동 기준17142ed 위에서 두 동작을 수정했다.

## 변경

- 카드 전체(제목·본문·이미지·여백)를 누르면 해당 레시피 상세로 이동한다. 기존>버튼도 유지하며 별표 터치는 즐겨찾기만 변경한다. 부모 클릭으로 상세가 중복 실행되지 않도록 실제 터치 UI 검사를 했다.
- AI 제안 버튼은 같은 재고에서도 다시 누를 수 있다. AI 요청 중에만 중복 전송을 막고, 성공·거절·오류 후에는 다시 활성화한다. 일반 목록 요청/오류는 별도의 명시적 AI 요청을 차단하지 않는다.
- 사용자가 다시 누를 때마다 기존`POST /recipes/recommendations`에 새 요청을 보낸다. 자동 반복/자동 재시도는 추가하지 않았다. 서버 선택/수정 한도1정책은 그대로라 같은 재료에서 같은 요리가 다시 선택될 수도 있다.
- 같은 재고에서 이전 다른 요리의 제안은 유지하고, 새 응답에 포함된 요리의 상태와 제안을 갱신한다. 재고·알레르기·도구 조건 변경 시 캐시는 비우고 오래된 응답을 버리는 기존 동작을 유지한다. 이미지 URL도 유지한다.

- 변경 전 단위 검사9개 중4개 실패로 재요청 잠금을 재현했다. 일반 목록 오류와 독립적인 AI 요청 조건도 별도1개 실패로 재현했다.

- 수정 후 JVM 전체95개 통과(실패/오류/스킵0), lint오류0/경고36/hint1, Cloud Test 앱·테스트 빌드 성공.
- 실제 휴대폰 레시피 UI7개 전부 통과. 제목/본문/이미지 실제 터치, 별표 실제 터치의 분리, 동일 재고 AI 버튼 재활성·새 요청2회, 상세 원본/제안 토글과 정렬을 포함한다. 이전 이미지 응답 필드와 캐시 무효화 검사도 단위 묶음에서 통과했다.
