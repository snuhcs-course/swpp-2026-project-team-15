# 냉장고 아이콘·정렬 로컬 확인

## 변경 내용

- 28종 단색 선 아이콘을 Android 벡터로 포함하고, 각 식재료에 CSV의 배경색을 적용합니다.
- 냉장고 상단에 추가순·가나다순·분류순 메뉴를 제공합니다. 초기값은 분류순입니다.
- 추가순은 먼저 저장한 재료부터 표시합니다. 정렬은 화면용 복사본에만 적용하여 저장된 재고 순서를 바꾸지 않습니다.
- 가나다순은 분류 구분 없이 전체 재료명을 한국어 사전순으로 정렬합니다.
- 분류순은 대분류 제목으로 묶고 같은 분류 안에서 가나다순으로 정렬합니다.
- 기본 재료 체크를 다시 저장해도 계속 보유 중인 재료는 기존 추가 위치를 유지합니다. 새로 선택한 재료만 뒤에 붙이고 삭제 후 재등록한 재료도 맨 뒤로 갑니다.
- 이름을 모르는 직접 입력 재료는 기타 아이콘·중립 배경으로 표시하며 삭제도 가능합니다.
- 달걀→계란, 후춧가루→후추는 표시용 별칭입니다. 재고 이름과 삭제 기준은 바꾸지 않습니다.

## 직접 확인할 순서

1. 로컬 Cloud Test 앱의 냉장고에서 각 재료의 그림·배경색·이름을 확인합니다.
2. ‘정렬: 분류순’을 눌러 세 옵션을 전환합니다. 분류순에서는 대분류 제목이, 나머지 두 모드에서는 평평한 선반 목록이 나타납니다.
3. 예를 들어 김치 → 마늘 → 다진마늘 → 계란 순서로 등록하면 추가순은 그 순서이고, 가나다순은 계란 → 김치 → 다진마늘 → 마늘입니다.
4. 관리 모드에서 마늘만 삭제하면 다진마늘은 유지되어야 합니다. 같은 아이콘을 써도 재료는 별개입니다.
5. 소금·식용유·고춧가루를 등록해 공통 양념통과 서로 다른 배경색을 확인합니다.
6. 목록에 없는 이름을 직접 등록해 대체 아이콘을 확인합니다. 삭제 확인창의 취소와 실제 삭제도 확인합니다.
7. 기본 재료 체크에서 기존 선택을 유지하고 새 재료만 추가한 뒤, 추가순에서 기존 재료의 위치가 유지되는지 확인합니다. 앱 재시작 후에도 재고의 저장 순서는 유지됩니다.

현재는 선택한 정렬 방식 자체를 영구 설정으로 저장하지 않습니다. 화면 상태 복원·탭 복귀에는 유지되지만 앱 새 시작에서는 분류순이 초기값입니다. 기존 저장소에 추가 시각이 없으므로 이전 버전에서 이미 재배치된 과거 순서를 복원하지는 않습니다.

## 코드와 데이터

- `android/app/src/main/assets/ingredient_presentation.csv`: 앱에서 실제 읽는 별도 매핑 CSV. 원본 560종 ID·이름과 8개 열을 유지합니다. 앞으로 앱 표시 정보를 조정할 때 이 파일을 수정합니다.
- `domain/IngredientPresentation.kt`: CSV 검증, 표시용 별칭·대체 아이콘, 대분류 순서, 한국어 정렬. Android 런타임과 독립된 단위 테스트 대상입니다.
- `data/local/IngredientPresentationProvider.kt`: 앱에 포함된 CSV를 한 번 읽어 캐시합니다.
- `ui/fridge/FridgeScreen.kt`, `FridgeSortDropdown.kt`: 정렬 상태와 화면용 목록을 연결합니다.
- `ui/fridge/components/FridgeShelves.kt`: 분류 제목·선반을 표시합니다. 빈 냉장고도 기본 선반을 유지합니다.
- `ui/fridge/components/IngredientComponent.kt`, `IngredientIconResources.kt`: 원형 배경과 아이콘 리소스를 연결합니다.
- `domain/FridgeInventory.kt`, `data/local/FridgeRepository.kt`, `viewmodel/FridgeViewModel.kt`: 체크박스 재선택에서 보유 중인 재료의 추가 순서를 유지합니다.
- `res/drawable/ic_ingredient_*.xml`: SVG와 같은 경로·선 색·선 굵기의 28종 벡터입니다. 별도 비트맵이나 외부 이미지 요청은 없습니다.

원본 entities/Ingredient.csv, DB 스키마, 서버 추천·인식 API, 기본 서버 주소는 수정하지 않았습니다. 매핑에는 검토가 필요한 22개 행과 조리 소모품 5개가 보존되어 있습니다. 분류는 정렬용이며 알레르기 분류가 아닙니다. CSV 재배포 조건 확인 전까지 이 변경은 로컬에 유지합니다.

## 검증 기록

최종 단위 테스트 50개, 에뮬레이터 UI 테스트 19개가 실패·오류·건너뛰기 없이 통과했고 lintDebug와 Cloud Test 빌드도 성공했습니다. 최신 앱은 에뮬레이터에 설치·실행했고 로컬 mock 서버로 연결했습니다. 현재 초기 별명 설정 화면이므로 온보딩에서 기본 재료를 체크한 뒤 냉장고 화면을 확인하면 됩니다.
