CSV 묶음은 Git 밖에서 전달된다. 조리도구·알레르겐 관계 테이블은 비어 있다. 원본 양은 1인분으로 정리해야 한다. 제공기관은 대표·단계 이미지 URL 필드를 사용하지 않는다고 답했으며, 선택한 요리의 이미지는 별도로 구해야 한다.

## 남은 통합 작업

1. 사진에서 후보 재료를 돌려주는 API와, 확정 재고·프로필에서 레시피를 돌려주는 API의 계약과 구현.
2. Android의 목업 응답을 실제 API로 교체하고 사용자 상태를 저장. 인식 후보의 사용자 확인·수정 단계 유지.
3. 실제 사진으로 누락·오탐·수정 부담을 확인. 현재 연구 수치는 모의 재료 문자열 결과이며 실제 사진 성능이 아니다.
4. 1인분 후보 레시피를 고르고 양·재료명·조리도구·알레르겐을 검수.
5. AI 레시피 조정의 허용 범위와 금지 조건을 정하고 원본과 생성된 변경을 구분.

수업 제공 OpenAI API 키(약 20달러 한도), GPU·CPU 서버는 논의된 자원이다. 접근·배포 조건을 확인하기 전에는 운영 의존성으로 가정하지 않는다.
