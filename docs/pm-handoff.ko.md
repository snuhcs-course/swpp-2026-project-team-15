# PM 인수인계 및 운영 안내

[English](pm-handoff.md) · [한국어](pm-handoff.ko.md)

Iteration 1은 2026-10-09 종료를 기준으로 한다. 일정표에는 권혁준이 Iteration 1 PM, 최아윤이 Iteration 2 PM으로 기재돼 있다. 이후 순번은 최신 일정표에서 확인한다.

## 무엇을 어디에 기록하는가

| 항목 | 기준 위치 | 갱신 시점 |
| --- | --- | --- |
| 작업, 담당, 예정·실제 시간, 최종 커밋 | 팀 일정표(`team15-iter1-schedule.xlsx`는 Iteration 1 제출본) | 작업 추가·완료 및 제출 전 |
| 코드와 검토 | Git 브랜치와 PR | 각 구현 변경 |
| 회의 결과 | [회의 기록](meetings/README.ko.md) | 팀·TA 회의 후 |
| 제품·기술 결정 | [결정 로그](decisions.ko.md) | 선택 또는 변경 시 |

| 현재 구현 상태 | [iteration 현황](iterations/iteration-1-status.ko.md) | 각 iteration 종료 시 |

코드 저장소와 Wiki는 별개의 Git 저장소이므로 코드 PR을 병합해도 Wiki는 자동으로 바뀌지 않는다.

## 매 iteration의 절차

1. **시작:** 이전 현황·회의록을 읽고 PM, 담당, 목표, 완료 근거, 다음으로 넘긴 일을 일정표에서 확인한다. 제안을 구현 완료로 간주하지 않는다.
2. **계획:** 기존 `P` 번호를 유지한다. 추가 작업은 날짜에 따라 `A1`, `A2` 식으로 기록한다. 실제 참석·작업한 사람만 참가자·작업자로 표시한다. 산출물이 구별되도록 작업을 쪼갠다.
3. **진행:** 주제별 브랜치와 PR을 사용하고 일정 작업을 커밋·PR에 연결한다. 다른 브랜치의 존재만으로 통합 완료를 주장하지 않는다.
4. **회의:** [회의 템플릿](meetings/TEMPLATE.ko.md)에 결정·검토안·담당·기한을 적고 중요한 선택은 결정 로그와 Wiki에도 반영한다.
5. **종료:** 실제 상태와 사람/에이전트 시간을 맞추고 완료 작업의 최종 커밋을 적는다. 링크, 데이터 수, 데모 동작, 문서 주장을 실제 브랜치와 대조한다. 못 마친 작업은 다음 iteration으로 명시적으로 넘긴다.
6. **제출:** 검토된 내용을 지정 이름으로 내보낸다. Iteration 1 ZIP은 `team15-iter1.zip`이며 reqspec·design·schedule·AI collaboration report의 지정 파일 4개를 담는다. eTL 마감 시각과 업로드 결과를 별도로 확인한다.

## 브랜치·데이터 원칙

- `main`은 통합 브랜치다. Iteration 1 Android, 레시피 DB, 연구 결과는 각각 별도 브랜치에 있다. [현황](iterations/iteration-1-status.ko.md)을 먼저 읽는다.
- 기능은 범위가 좁은 브랜치와 PR로 관리한다. PR에 범위, 근거, 남은 한계, 검토 담당을 적는다.
- 개인 대화 원문, 비밀번호, API 키, 로컬 DB, 별도 배포 CSV는 올리지 않는다. 회의는 필요한 결정만 요약한다.
- 수업 제공 API 키의 예산·사용량을 합의하고 Git 밖에 보관한다. 서버 제공 공지만으로 배포 완료라고 적지 않는다.

## Iteration 2 인계 목록

- Android 목업을 대체할 두 서버 흐름과 정상·빈·오류 응답을 합의한다.
- 1인분 요리 후보와 표준 재료 목록을 고르고 양·도구·알레르겐 정보를 채운다.
- 실제 사진으로 인식 실패를 기록하고 사용자 수정·양념 체크 방식을 살핀다.
- 새로고침, 부족한 재료 제안, 제한된 AI 치환을 약속하기 전에 규칙을 정한다.
- 재고 저장 위치, 백엔드, ORM을 결정하면 결정 로그와 Wiki를 갱신한다.
- TA 조치와 일정표를 맞추고 못 마친 작업을 완료로 둔 채 넘기지 않는다.

나가는 PM은 최신 일정표, 열린 PR·브랜치, TA 피드백, Wiki, 데모 방법, 미결정 목록과 접근 권한을 다음 PM에게 전달한다. 자격 증명은 저장소에 적지 않는다.
