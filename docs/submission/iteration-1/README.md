The English versions are intended for the required GitHub Wiki pages and course PDFs. Korean versions help the team review decisions and hand work to future PMs. When one version changes, update the other and the corresponding Wiki page in the same documentation change.

## PDF preparation

1. Open the English Markdown or its Wiki page and copy the prose and tables into Word.
2. Let GitHub render each fenced `mermaid` block. Capture the rendered diagram at a readable size and insert that image in Word at the diagram's position. Add a brief caption. Avoid pasting the Mermaid source code as the final figure.
3. For Requirements & Specifications, also insert the team's actual Figma wireframes with arrows for actions, allowed/invalid input, and failure paths. The Mermaid user-flow diagram is an overview and does not replace screen wireframes.
4. Check headings, tables, images, source links, page breaks, and language in Word. Export PDF with the exact course filenames: `team15-iter1-reqspec.pdf` and `team15-iter1-design.pdf`.
5. Reopen the exported PDFs and inspect every page before placing them in `team15-iter1.zip` with the schedule and AI collaboration report.

The course requires English documents on the GitHub Wiki as well as PDF copies for each iteration. If the Word copy is edited, apply the same substantive changes to the English Markdown and Wiki so the versions agree.
