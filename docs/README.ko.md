# 프로젝트 문서 안내

[English](README.md) · [한국어](README.ko.md)

이 폴더는 코드와 함께 관리할 팀 운영 기록이다. 기술 연구, 설계, 레시피 데이터의 상세 설명은 [GitHub Wiki](https://github.com/snuhcs-course/swpp-2026-project-team-15/wiki)에 있다. 이 한국어 파일들은 **검토용 대응본**으로, 영어 원본과 의미가 달라지지 않도록 확인한 뒤 Git에 올릴 예정이다.

## 먼저 볼 문서

- [Iteration 1 현황](iterations/iteration-1-status.ko.md): 실제로 만든 것과 남은 작업.
- [회의 기록](meetings/README.ko.md): 날짜별 논의 요약과 결정.
- [결정 로그](decisions.ko.md): 확정된 방향과 아직 비교 중인 선택.
- [PM 인수인계](pm-handoff.ko.md): 매 iteration 운영 절차와 인수인계 목록.
- [Iteration 1 요구사항·설계 문서](submission/iteration-1/README.md): Wiki·PDF 준비에 사용할 한·영 Markdown 원본.

회의 기록은 개인 메시지 원문이 아니라 프로젝트에 필요한 논의 요약이다. 범위나 구조에 영향을 주는 결정은 결정 로그와 관련 Wiki 문서에도 반영한다.
